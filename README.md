# CodSoft C++ Programming Virtual Internship

This repository contains the projects completed during my **C++ Programming Virtual Internship at CodSoft**.

The internship provided an opportunity to apply C++ programming concepts through practical, project-based tasks while improving problem-solving and application development skills.

## Internship Details

- **Organization:** CodSoft
- **Domain:** C++ Programming
- **Internship Type:** Virtual Internship
- **Duration:** 10 September 2026 – 10 October 2026
- **GitHub Repository:** Maintained as a dedicated repository for the internship projects

## Completed Tasks

### Task 1 – Random Number Guessing Game

A graphical number guessing game created using C++ and the Windows API.

The application:

- Generates a random number between 1 and 100
- Takes guesses from the user
- Gives "Too High" or "Too Low" feedback
- Keeps track of the number of attempts
- Shows the result after the correct number is guessed
- Provides an option to start a new game

**Technologies:** C++, Win32 API

[View Task 1](./Task-1-Random-Number-Guessing-Game/)

---

### Task 2 – Tic-Tac-Toe Game

A two-player Tic-Tac-Toe game developed in C++ with both console-based and native Windows GUI interfaces.

The application features:

- Two-player gameplay
- 3×3 game board
- X and O players
- Win detection
- Draw detection
- Invalid move handling
- Play Again functionality
- Console mode
- Win32 GUI mode

**Technologies:** C++, Win32 API

[View Task 2](./Task-2-Tic-Tac-Toe/)

---

### Task 3 – To-Do List Manager

A graphical To-Do List Manager developed using C++ and the Windows API.

The application allows users to:

- Add new tasks
- View existing tasks
- Mark tasks as completed
- Remove tasks
- Check pending and completed task counts
- Manage tasks through a graphical interface

**Technologies:** C++, Win32 API, Windows Common Controls

[View Task 3](./Task-3-To-Do-List/)
